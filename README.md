# Combat Universe

A Vite + React + TypeScript prototype for a living combat-history simulator.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The game stores its three save slots in the browser's local storage.

## Current playable loop

- Create a fresh universe in one of three save slots.
- Run a 20-round, eight-promotion snake draft (160 Legend/Epic stars).
- Auto-pick individual selections, rounds, or the entire draft.
- Simulate months and years of events.
- Track male and female championships separately.
- Follow fame, viewers, revenue, wins, reigns, promotion histories, and chronicles.
- Inspect clickable fighter and promotion detail modals.
- Filter Almanac statistics by All / Male / Female.
- Watch promotions compete for the lower-rarity free-agent pool.
- Edit promotion identities, move fighters, merge companies, and create splinter promotions.
